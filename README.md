# Ithaka

> Jogo 2D Indie desenvolvido em C com Allegro, inspirado na obra Odisseia, de Homero.

---

## Sobre o Projeto

Ithaka é um projeto acadêmico desenvolvido para a disciplina de Projeto Integrador do Bacharelado em Ciência da Computação.

O jogo busca recriar, em uma experiência 2D, a jornada de retorno de Odisseu para Ítaca, utilizando mecânicas de exploração, combate e progressão em fases.

Além da proposta narrativa, o projeto também serve como aplicação prática de conceitos de:

* Engenharia de Software
* Estruturação de Sistemas
* Programação em C
* Desenvolvimento de Jogos
* Arquitetura de Código
* Lógica e Mecânicas de Gameplay
